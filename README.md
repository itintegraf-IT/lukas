# Integraf — Výrobní KPI Reporting

Interní webová aplikace pro sledování výkonnosti výrobních strojů.

## Použití

Otevřít aplikaci: [integraf-kpi.html](./integraf-kpi.html)

## Stroje

V1 · V2 PUR · V2 BLOKY · STAHL 82 · STAHL KH 78 · MBO · BRAUSSE BORA · OKÉNKOVAČKA · LEPIČKA OMEGA

## Technologie

- Data uložena v Supabase (sdílená cloudová databáze)
- Běží přímo v prohlížeči, bez instalace
- Vstupní data: exporty .xlsx ze systému sběru výroby Heidelberg
